Reliability & Design

Built for Hugging Face Spaces constraints

Designed to handle container sleep timeouts, CPU quotas, and multi-model memory warmups without failure cascading.

01

Memory Warmup at Boot

Packages register optional non-blocking warmup routines. Transformer weights and decision trees are loaded into RAM before traffic arrives, avoiding cold-hit timeouts.

02

Streaming Payload Guards

A custom Starlette middleware counts raw stream bytes in chunks. Oversized payloads reject immediately at 10 MB before exhausting container RAM or blocking the event loop.

03

Non-Failing Fault Isolation

If an upstream package raises an import error or fails warmup, the gateway marks overall health as degraded, logs the traceback, and serves remaining subprojects uninterrupted.

04

Deterministic Lockfiles

A 7-day scheduled cron tests upstream git semver releases, compiles verified hashes via uv, and pushes to main to auto-rebuild Hugging Face Spaces.

System Topology

Request Ingress & Subproject Routing Flow

Single Container • Zero Network Hops
1. Container Packing vs Microservices

Free-tier Hugging Face Spaces sleep after periods of inactivity. Deploying each subproject to an isolated Space multiplies cold starts and introduces 80–120ms of cross-space network latency. Packing standalone Python packages into a single container uses the full 16 GB memory allocation, shares the PyTorch runtime, and routes requests in memory.

2. Prefix-Based Fault Isolation

Subprojects install from git tags into the Python environment and expose independent router instances. The gateway attaches them under explicit path prefixes (/heartflow, /semantic). If an upstream dependency fails during import or warmup, the gateway logs the traceback, reports degraded health, and continues serving the remaining subprojects.

3. Streaming Ingress Guards

Before reaching router handlers, incoming requests pass through Starlette middleware that counts raw stream bytes in chunks. Oversized payloads reject immediately at 10 MB with HTTP 413, preventing unbounded memory allocation from exhausting the container RAM or stalling the event loop.
